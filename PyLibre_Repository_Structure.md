# PyLibre Repository Structure

This document outlines the structure of the PyLibre repository, which provides tools for working with the Libre blockchain, particularly for DEX operations and trading strategies.

## Root Directory

- **config/**: Configuration files for the application
- **examples/**: Example code and usage patterns
- **logs/**: Log files generated by the strategies and other components
- **scripts/**: Executable scripts for running strategies and utilities
- **shared_data/**: Shared data files, including price data
- **src/**: Source code for the PyLibre package
- **tests/**: Test files for the codebase
- **.venv/**: Python virtual environment (not tracked in git)
- **pyproject.toml**: Python package configuration
- **README.md**: Project documentation

## Source Code (`src/pylibre/`)

The main package is organized into several modules:

### Core Modules

- **client.py**: Core client for interacting with the Libre blockchain
- **dex.py**: DEX client for interacting with the decentralized exchange
- **cli.py**: Command-line interface for the PyLibre tools

### Strategies (`src/pylibre/strategies/`)

Trading strategies for the DEX:

- **orderbookmaker.py**: Strategy for creating a spread of orders around a center price
- **orderbookfiller.py**: Strategy for filling orders in the orderbook
- **__init__.py**: Exports the strategies for easy importing

#### Strategy Templates (`src/pylibre/strategies/templates/`)

- **base_strategy.py**: Base class for all trading strategies, providing common functionality

### Utilities (`src/pylibre/utils/`)

Utility functions and classes:

- **logger.py**: Logging utilities for strategies and other components
- **shared_data.py**: Utilities for sharing data between strategies
- **binance_api.py**: Utilities for interacting with the Binance API

### Price Feed (`src/pylibre/price_feed/`)

Components for fetching and managing price data:

- **base.py**: Base class for price feed sources
- **binance_source.py**: Price feed source from Binance
- **fixed_source.py**: Price feed source with fixed prices
- **factory.py**: Factory for creating price feed sources
- **__init__.py**: Exports the price feed components

## Scripts (`scripts/`)

Executable scripts for various purposes:

### Strategy Scripts

- **run_orderbook_maker.py**: Script to run the OrderBookMakerStrategy
- **orderbook_maker_strategy.py**: Original implementation of the OrderBookMakerStrategy
- **run_strategy.py**: Generic script for running strategies
- **run_trading.py**: Script for running trading operations

### Utility Scripts

- **cancel_all_orders.py**: Script to cancel all orders for an account
- **check_balances.py**: Script to check account balances
- **check_orderbook.py**: Script to check the orderbook
- **fetch_prices.py**: Script to fetch prices from external sources
- **package.py**: Script for packaging the PyLibre package

### Test Scripts

- **test_*.py**: Various test scripts for different components and scenarios

## Key Components

### Logger (`src/pylibre/utils/logger.py`)

The logger provides a consistent logging interface for strategies and other components:

- **StrategyLogger**: Class for logging strategy operations
  - Creates log files in the `logs/` directory
  - Supports different log levels (DEBUG, INFO, WARNING, ERROR)
  - Prevents duplicate log handlers

### Shared Data (`src/pylibre/utils/shared_data.py`)

Utilities for sharing data between strategies:

- **write_price()**: Function to write price data to a file
- **read_price()**: Function to read price data from a file
- Uses thread locking to prevent race conditions

### OrderBookMakerStrategy (`src/pylibre/strategies/orderbookmaker.py`)

Strategy for creating a spread of orders around a center price:

- **__init__()**: Initializes the strategy with parameters
- **get_market_price()**: Gets the current market price
- **generate_signal()**: Generates trading signals
- **generate_sell_prices()**: Generates prices for sell orders
- **generate_buy_prices()**: Generates prices for buy orders
- **generate_order_quantities()**: Generates quantities for orders
- **place_orders()**: Places orders based on the generated signal
- **run()**: Runs the strategy
- **check_balances()**: Checks account balances
- **adjust_orders_for_balance()**: Adjusts orders based on available balances

### BaseStrategy (`src/pylibre/strategies/templates/base_strategy.py`)

Base class for all trading strategies:

- Provides common functionality for strategies
- Handles order placement, cancellation, and other operations
- Implements logging and error handling

### Price Feed (`src/pylibre/price_feed/`)

Components for fetching and managing price data:

- **BasePriceFeed**: Base class for price feed sources
- **BinancePriceFeed**: Price feed source from Binance
- **FixedPriceFeed**: Price feed source with fixed prices
- **PriceFeedFactory**: Factory for creating price feed sources

## Workflow

1. **Initialization**: Strategies are initialized with parameters
2. **Price Fetching**: Strategies fetch prices from price feeds
3. **Signal Generation**: Strategies generate trading signals
4. **Order Placement**: Strategies place orders based on signals
5. **Monitoring**: Strategies monitor the orderbook and adjust orders
6. **Logging**: Operations are logged for monitoring and debugging
